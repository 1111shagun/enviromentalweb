## 🌱 About the Project

**EcoLife** is an environmental awareness website designed to encourage people to adopt sustainable habits and protect our planet.

The website provides useful information about environmental protection, practical eco-friendly solutions, responsible waste disposal, and everyday actions that can help reduce pollution.

It also includes interactive JavaScript features that allow visitors to explore waste-management tips, test their environmental knowledge, and select a green activity.

> 💚 Our motto: Small steps today can create a greener tomorrow!

## 🚀 How to Run

Follow these simple steps to explore EcoLife locally.

**Step 1:** Download or clone the project repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2:** Open the project folder.

**Step 3:** Make sure all three files are in the same folder:

- `index.html`
- `style.css`
- `script.js`

**Step 4:** Open `index.html` in your web browser.

**Step 5:** Explore the website, switch themes, try the quiz, and select your favourite green activity!

No additional libraries or installation commands are required for the basic website.

## 🧩 Interactive Features

### 🌙 1. Dark Mode

Click the **Dark Mode** button in the navigation bar to switch the website's appearance. Click again to return to light mode.

### ♻️ 2. Waste Management Explorer

Choose a waste category to discover appropriate disposal guidance.

- 🍂 **Wet Waste:** Learn about composting food scraps and vegetable peels.
- 📦 **Dry Waste:** Learn to separate paper, cardboard, and recyclable items.
- 🔋 **E-Waste:** Learn about responsible disposal of old electronics and batteries.

### 🧠 3. Environmental Awareness Quiz

Answer the question about reducing waste and click **Check Answer** to receive instant feedback.

### 🌱 4. My Green Activity

Select an activity such as planting trees, saving water, recycling waste, or avoiding plastic. Submit your choice to see a confirmation message.

### 📅 5. Automatic Footer Year

JavaScript automatically displays the current year in the website footer.
